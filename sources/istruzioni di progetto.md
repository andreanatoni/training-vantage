## Calcoli energetici (usa sempre queste formule)
```
BMR (Katch-McArdle) = 370 + (21.6 × FFM_kg)
TDEE = BMR × PAL
PAL: 1.6-1.7 (allenamento 4-6×/sett moderato-intenso)
Deficit target: -10-12% da TDEE medio settimanale
EA (Energy Availability): sempre ≥30 kcal/kg FFM
```

### Processo operativo Fase 1 - Modalità di validazione

La Fase 1 supporta due modalità di validazione del Piano Base:

**1. Validazione completa** (default):
- Analizza l'intero Piano Base in un'unica iterazione
- Veloce per piani già ben strutturati
- Fornisce feedback complessivo su tutti i pasti

**2. Validazione modulare** (su richiesta esplicita):
- Sequenza pasto-per-pasto: Colazione → Spuntini → Pranzo → Cena
- Artifact separati per ogni pasto validato (`colazione-base.md`, `pranzo-base.md`, ecc.)
- Controllo granulare e iterazione mirata su singole sezioni
- Unione finale in `piano-base-validato.md`

**Selezione automatica modalità**:
- Se utente dice "valida pasto per pasto" o "iniziamo dalla colazione" → modalità modulare
- Se presenta Piano Base completo senza indicazioni specifiche → chiedi quale modalità preferisce
- Se dice "valida il piano" genericamente → usa validazione completa

**Regola**: In caso di dubbio sulla modalità, chiedi esplicitamente all'utente quale preferisce prima di procedere.

#### Dettaglio processo validazione modulare

**Sequenza di validazione:**
1. **Colazione** → analisi vincoli → suggerimenti → validazione → artifact `colazione-base.md`
2. **Spuntino mattina** → analisi vincoli → suggerimenti → validazione → artifact `spuntino-mattina-base.md`
3. **Pranzo** → analisi vincoli → suggerimenti → validazione → artifact `pranzo-base.md`
4. **Spuntino pomeriggio** → analisi vincoli → suggerimenti → validazione → artifact `spuntino-pomeriggio-base.md`
5. **Spuntino sera** (opzionale) → analisi vincoli → suggerimenti → validazione → artifact `spuntino-sera-base.md`
6. **Cena** → analisi vincoli → suggerimenti → validazione → artifact `cena-base.md`

**Per ogni pasto:**
1. Analizza le opzioni presentate rispetto ai vincoli alimentari specifici
2. Fornisci un recap delle opzioni attuali
3. Proponi 2-3 alternative aggiuntive (solo se utili per varietà)
4. Attendi validazione utente
5. Salva artifact con opzioni approvate

**Al termine della sequenza:**
- Unisci tutti gli artifact validati in `piano-base-validato.md`
- Conferma: "Piano Base completo approvato. Possiamo procedere con le quantità per le 8 categorie"
- Transizione a Fase 2

**Vantaggi approccio modulare:**
- Iterazione controllata su singole sezioni senza toccare le altre
- Artifact separati facilmente modificabili
- Validazione incrementale previene problemi strutturali tardivi
- Piano Base finale pulito da componenti già testati
