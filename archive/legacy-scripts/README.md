# Legacy Scripts Archive

Questa cartella contiene script storici rimossi dal runtime operativo.

Contenuto:
- `planner/`: vecchio stack parser/generatore piani markdown
- `tools/`: utility one-shot e script sperimentali non usati dal dispatcher `./tv`

Nota:
- Il path runtime supportato e' solo tramite `./tv` e i package in `scripts/`.
- Questi file sono mantenuti solo per audit/storia, non per uso operativo quotidiano.
